╔══════════════════════════════════════════════════════════════════════════════╗
║ Runtime Optimization Strategies                                             ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. Icon Caching
   ┌────────────────────────────────────────────────────────────────┐
   │ Dictionary<string, Sprite> _cachedIcons                        │
   │ ├─ Icons generated once on first request                       │
   │ ├─ Reused for all future UI rebuilds                           │
   │ └─ No file I/O overhead, no missing asset errors               │
   └────────────────────────────────────────────────────────────────┘

2. Material Instancing
   ┌────────────────────────────────────────────────────────────────┐
   │ new Material(shader) for each UI element                       │
   │ ├─ Allows per-element color/glow customization                 │
   │ ├─ GPU batching still works for same shader                    │
   │ └─ Acceptable overhead for ~10-15 UI elements                  │
   └────────────────────────────────────────────────────────────────┘

3. Layout Rebuild Optimization
   ┌────────────────────────────────────────────────────────────────┐
   │ Canvas.ForceUpdateCanvases()                                   │
   │ LayoutRebuilder.ForceRebuildLayoutImmediate(rt)                │
   │ ├─ Called ONCE after all elements created                      │
   │ └─ Prevents multiple layout recalculations                     │
   └────────────────────────────────────────────────────────────────┘

4. Raycast Filtering
   ┌────────────────────────────────────────────────────────────────┐
   │ raycastTarget = false for:                                     │
   │ ├─ Text elements (except buttons)                              │
   │ ├─ Icons (visual only)                                         │
   │ ├─ Borders and glow effects                                    │
   │ └─ Background panels (unless interactive)                      │
   │ Result: 60-70% reduction in raycast checks                     │
   └────────────────────────────────────────────────────────────────┘

5. Shader Parameter Efficiency
   ┌────────────────────────────────────────────────────────────────┐
   │ Material properties set once during creation:                  │
   │ ├─ _CornerRadius, _EdgePadding → Static values                 │
   │ ├─ _Aspect → Calculated once per element                       │
   │ └─ _PulseEnabled → Only 1 element (CONNECT) has animation      │
   └────────────────────────────────────────────────────────────────┘
